# 📝 Formulário de Cadastro - React + Vite

## 📖 Descrição

Este projeto é uma aplicação Front-End desenvolvida em **React** utilizando **Vite**, que consiste em um formulário de cadastro de usuários dividido em múltiplas etapas.

O sistema realiza validações em cada etapa antes de permitir o avanço, garantindo que os dados sejam preenchidos corretamente. Após o envio, uma tela de sucesso é exibida temporariamente.

---

## 🚀 Tecnologias utilizadas

- React  
- Vite  
- JavaScript  
- CSS  

---

## ⚙️ Instalação

1. Clone o repositório:

git clone https://github.com/seu-usuario/seu-repo.git  

2. Entre na pasta do projeto:

cd seu-repo  

3. Instale as dependências:

npm install  

---

## ▶️ Como executar o projeto

npm run dev  

O projeto será iniciado em modo de desenvolvimento.  
Acesse no navegador o endereço exibido no terminal (geralmente):

http://localhost:5173  

---

## 🧩 Funcionalidades

- Formulário dividido em 3 etapas  
- Validação de nome (sem números, entre 2 e 30 caracteres)  
- Validação de email com domínios específicos  
- Formatação automática de telefone  
- Validação de senha e confirmação  
- Aceite obrigatório dos termos e condições  
- Barra de progresso visual  
- Tela de sucesso após envio  

---
